Basic commands of wsl

1. touch

File Creation


THe touch command creates a new empty file. If the file already exists it simply updates the file's last modified timestamp instead of changing it's content. It's one of the simplest way to create a file directly from the command pallette.

2. mkdir

Folder Creation


The mkdir command creates a new empty folder at the location you specify.
Syntax: mkdir foldername
Example:mkdir project
Output: (no output- the folder project is created in the current directory.)

3. cd

Changing directroy


The cd command changes the current working directory, moving you into a different fodler in the terminal.
Syntax: cd foldername
Example: cd project
Output: (prompt changs to show you are now inside -/project)
